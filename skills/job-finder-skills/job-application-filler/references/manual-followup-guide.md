# Manual Follow-Up Guide

Use this when the agent cannot finish directly but can tell the user what to do next.

## Common Follow-Up Types

- `already_applied`
- `assessment_required`
- `email_verification_required`
- `calendar_booking_required`
- `identity_verification_required`
- `external_questionnaire_required`
- `broken_portal`

## What To Tell The User

- What exact screen or message was reached
- Why the application could not be completed automatically
- The next concrete step the user should take
- Whether the application appears partially complete or not submitted yet

## Examples

- Already applied:
  - Tell the user the site reports an existing application and no new submission should be attempted.
- Assessment required:
  - Tell the user an assessment or test must be completed and where to click or look next.
- Email verification:
  - Tell the user to open their email, complete verification, then resume or restart.
- Scheduler:
  - Tell the user the site moved into interview scheduling and they should choose a slot manually.
- Broken portal:
  - Tell the user the site is not functioning reliably and include the blocking message if visible.
