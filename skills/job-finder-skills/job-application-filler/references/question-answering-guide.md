# Question Answering Guide

## Safe To Auto-Answer From Stored Facts

- Name and contact details
- LinkedIn, GitHub, website, portfolio
- Work authorization
- Sponsorship needed
- Notice period
- Earliest start date
- Desired salary when present
- Relocation willingness when present

## Salary Questions

- Match the stored salary to the visible format when possible.
- If the site wants a range, choose the closest truthful range.
- If the site asks for hourly pay and only annual pay is stored, ask the user.

## Cover Letter Text Boxes

- Read the staged cover letter text file from CUSTOM RULES.
- Paste the text body rather than the markdown-with-line-break-tags version.

## Motivation Questions

- In `best_effort` mode, answer from the CV summary, visible job context, and staged cover letter text.
- Keep answers concise and factual.
- Do not claim tools, domains, or achievements that are not grounded in the source material.

## Always Ask The User

- Technical screening questions
- Architecture or system-design prompts
- Security clearance or export-control declarations
- Criminal history or legal attestations beyond simple required certifications
- Compensation negotiation questions not covered by stored salary data
- Long-form essays that need personal judgment beyond the available facts
